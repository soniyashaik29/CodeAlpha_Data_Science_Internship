# Unemployment Analysis with Python

## Project Overview

This project analyzes unemployment trends in India using Python. The objective is to understand unemployment patterns across different states, compare Urban and Rural unemployment rates, study the impact of Covid-19 on employment, and derive meaningful insights from the data.

---

## Objectives

- Analyze unemployment rate data.
- Perform data cleaning and preprocessing.
- Visualize unemployment trends across states.
- Study the impact of Covid-19 on unemployment.
- Compare Urban and Rural unemployment rates.
- Identify monthly and seasonal trends.
- Generate insights that can support economic and social policy decisions.

---

## Dataset Information

The dataset contains the following attributes:

- Region
- Date
- Frequency
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)
- Area (Urban/Rural)

---

- Python
- Pandas

### 1. Data Collection

- Imported unemployment dataset.

### 2. Data Cleaning

- Removed unnecessary spaces from column names.
