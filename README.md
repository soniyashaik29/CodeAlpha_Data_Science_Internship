# Data Science Projects

## Overview

This repository contains the successful completion of all assigned tasks for the CodeAlpha Data Science Internship Program.

The projects demonstrate practical applications of Data Science, Data Analysis, Data Visualization, and Machine Learning using Python and industry-standard libraries.

---

## Project Tasks Completed

### Task 1: Iris Flower Classification

#### Project Objective

Build a machine learning model to classify Iris flowers into different species based on sepal and petal measurements.

#### Key Activities

- Data Loading and Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Feature Selection
- Model Training
- Classification Evaluation

#### Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

#### Machine Learning Model

- Random Forest Classifier

#### Evaluation Metrics

- Accuracy Score
- Classification Report
- Confusion Matrix

#### Outcome

Successfully classified Iris flower species with high prediction accuracy.
