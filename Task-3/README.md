# Sales Prediction Using Python

## Overview

This project predicts product sales based on advertising expenditure across TV, Radio, and Newspaper channels.

## Business Problem

Organizations invest heavily in marketing campaigns. Understanding which advertising channel contributes most to sales can help optimize marketing budgets and improve profitability.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Machine Learning Algorithm

Linear Regression

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Selection
5. Model Training
6. Prediction
7. Performance Evaluation
8. Business Insights

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

## Key Findings

- TV advertising is the most influential marketing channel.
- Radio advertising also contributes significantly to sales growth.
- The model successfully predicts future sales with high accuracy.
