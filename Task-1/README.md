# Iris Flower Classification

## Project Overview

This project uses Machine Learning to classify Iris flowers into:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Algorithms Used

- Random Forest Classifier

## Results

Model Accuracy: 1.0+

## Visualizations

- Species Distribution
- Pairplot
- Correlation Heatmap
- Confusion Matrix
